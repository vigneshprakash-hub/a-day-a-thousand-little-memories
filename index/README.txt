HOW TO HOST
1. Put audio01.mp3 ... audio05.mp3 into  assets/audio/   (see AUDIO below)
2. Upload the whole "birthday-site" folder (keep the folder structure) to Netlify, Vercel, GitHub Pages, Cloudflare Pages, etc.
3. Open index.html — starry split-curtain, then the dashboard.
